BT 搜索结果备份仓库

本仓库保存 BT 搜索结果的网页版备份：磁力链接、可点击复制的 HTML 页面、可读结果清单。

## 目录结构

| 目录 | 内容 |
|---|---|
| `pages/` | 每个查询一个 `-links.html`（点一行即复制磁力）+ `index.html` 首页（带姓名筛选框） |
| `magnets/` | 每页对应的 `-magnets.magnet`（一行一个磁力，可直接拖进 BT 客户端批量导入） |
| `reports/` | 每页对应的 `-results.txt`（标题 / 大小 / 做种 / 来源 / 磁力的可读清单） |

## 规模

- 73 个查询页 + 首页
- 每页 113~300 条，两级去重后按作品折叠

## 来源

由 `bt-network-search` 技能生成（35 个公开索引器聚合，默认并发 28 源，两级去重）。

线上站点：http://8.134.195.243:8000/

## 使用

- `pages/index.html` 用浏览器打开即可，首页可按姓名筛选
- `magnets/*.magnet` 直接拖进 qBittorrent / Transmission 等客户端

## 备注

- 页面上的做种数来自索引站快照，**不等于当前在线 peer 数**；想看真实可下载状态需另做 announce 实测
- `.torrent` 文件（离线可用，不需等 peer 给 metadata）随站点另行提供，未包含在本仓库
